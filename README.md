# Ziyu (Colby) Wang — Academic Homepage

This is a lightweight static academic website.

## Files
- `index.html` — complete site with embedded CSS

## Publish options
You can upload `index.html` directly to:
- GitHub Pages
- Netlify
- Cloudflare Pages
- a standard web host

## Customize
Open `index.html` in any text editor and replace:
- the initials avatar (`ZW`) with a real photo if desired
- publication metadata/links
- thesis repository link when available
- CV link when available

The site has no external dependencies and works offline.
